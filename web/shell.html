CHIP-8 · emulator and debugger

CHIP-8 is a tiny virtual machine from 1977 — 35 instructions, 4 KB of memory and a 64×32 black-and-white screen. This is an implementation of it written from scratch in C++, compiled to WebAssembly, wrapped in a debugger that shows the machine working while it runs. Click the screen, then press A and D to play.

The six ROMs

Tab cycles through them. Every one is original, written by hand in CHIP-8 assembly, with the commented source kept in roms/src/.

Driving the debugger

Space
pause and resume
N
run exactly one instruction, while paused
Tab
load the next bundled ROM
Backspace
restart the current ROM
[ ]
instructions per frame — the emulator’s clock speed, 11 by default
F1–F5
toggle the five hardware quirks that real CHIP-8 interpreters disagree about: how shifts pick their operand, whether Fx55/Fx65 leave I moved, whether logic ops clear VF, whether draws wait for vblank, and whether sprites clip or wrap at the edges

What you are looking at

Top left is the emulated 64×32 display, scaled up 11×. The strip under it names the ROM and its controls.

Below that is a live disassembly. It parks over whichever stretch of code is running hottest rather than chasing the program counter, which at sixty frames a second is unreadable; the green wash on a row means it ran recently. Pause and it follows the program counter exactly, so N steps through line by line.

On the right is the machine itself: the sixteen V registers (highlighted amber for a moment when written), the program counter, index and timers, the call stack, the bytes around I, and the keypad. Nothing there is cached — it is read straight out of the interpreter each frame.

The keypad reads CHIP-8 value / your key. The original COSMAC VIP had a 16-key hex pad laid out 1 2 3 C / 4 5 6 D / 7 8 9 E / A 0 B F, mapped here onto the left block of a QWERTY keyboard — so pressing A lights CHIP-8 key 7.
